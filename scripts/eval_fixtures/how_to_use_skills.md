# how_to_use_skills.md

Agent Skills 是把专门工作流、领域知识和工具使用说明封装成可复用能力的模块。它适合沉淀重复出现、需要稳定步骤、依赖特定工具或包含领域判断的任务。

## SKILL.md 怎么写

每个 skill 目录必须包含 `SKILL.md`。`SKILL.md` 应该说明这个 skill 的触发条件、输入要求、执行步骤、工具依赖、产物格式和验证方式。说明要足够短，让模型先理解什么时候使用它，而不是一次性塞入所有细节。

## 创建步骤

创建一个新的 Skill 时，通常先新建 skill 目录，然后编写 `SKILL.md`，再按需添加 `scripts/`、`templates/`、`assets/` 或 `references/`。脚本适合承载可重复、容易出错或需要稳定执行的操作，模板适合保存固定产物结构，references 适合保存较长的补充说明。

## Progressive Disclosure

Progressive Disclosure 是指先只向模型暴露最关键的说明，再按需读取补充文件。这样可以避免一次性塞入过多上下文，也能让 skill 的启动成本更低。`SKILL.md` 应该像索引页，而不是把所有资料都塞进去。

## 什么时候用 Skill

当任务重复出现、需要稳定流程、依赖特定工具、包含领域知识，或者需要产出一致格式时，应该把流程沉淀为 Skill。如果任务只是一次性的简单问答，就不一定需要 Skill。

## 成功标准

一个好的 Skill 应该有清晰触发条件、可执行步骤、明确边界和验证方法。用户不需要反复提醒模型下一步做什么，模型也能根据 skill 说明稳定地产出结果。
